# ETS 2024

Home → ETS 2024 (`/ets-2024`) provides ten original tests, 2,000 questions, seven Parts per test, full tests with a 120-minute timer and untimed Part practice. Answers are graded on the server; skipped questions count as incorrect. Drafts stay in the current browser, isolated by account/test/Part. Submitted results use separate Supabase history and do not award EXP.

## Database prerequisite

Apply `supabase/migrations/202611020003_ets.sql` once after the four existing migrations, through the project's normal Supabase SQL Editor or CLI migration workflow. It adds `ets_sessions`, owner-only SELECT RLS and the server-only immutable `save_ets` RPC. A repeat request returns the original result; changed content with the same ID is rejected.

The live connected database was checked read-only during implementation and returned `PGRST205` (table absent). No SQL management connector or database connection credential is configured in this workspace, so this migration has not been applied remotely. Until it is applied, reading/practice/drafts work, but server submission/history cannot save. The pending submission remains in the browser for retry after migration. Do not claim live persistence has been verified before applying it.

## Source data and audio

`data/ets-2024/tests.json` contains native questions/passages and private answer keys. The server catalog projects only public fields. Do not move that JSON into `public`.

Retain the supplied `ETS 2024/AUDIO - ETS 2024/` directory on the Node server; audio is streamed through authenticated `/api/ets/audio` with HTTP byte ranges. Tests 1–5 use supplied Part recordings. Tests 6–10 use original full recordings with source-matched time ranges in `audio-timings.json`. Those ranges were verified by local announcement waveform matching and quiet-gap checks at 20 ms resolution, not by a human listening pass. Original recordings are unchanged.

The large MP3 source folder is not automatically embedded into a serverless bundle. A deployment must supply the same directory as a mounted asset directory, or explicitly move audio to private object storage and adapt the audio route. Run locally with the supplied folder for current use. `public/ets-2024/figures/` contains only the 60 original photographs and 50 necessary listening graphics, never full scanned pages.

Question choices and passage text are rendered directly in the interface. Spoken Part 1–2 alternatives are intentionally absent before grading. Transcript source PDFs have not been imported into the results; the UI only offers a transcript when a verified group transcript exists. No translation, invented explanation or unofficial 990-point conversion is added.

## Reproduce conversion

Use Python with pypdf, Pillow and numpy, plus Poppler `pdftoppm` and Windows OCR with English installed. The desktop bundled Python runtime has these dependencies. All recognition runs locally.

1. `python scripts/import-ets.py --prepare --keys`
2. `powershell -NoProfile -ExecutionPolicy Bypass -File scripts/ets-ocr.ps1 -ImageDirectory "<absolute-repository-path>/tmp/ets"`
3. `python scripts/ets-layout.py`
4. `node --test tests/ets-data.test.ts`

The answer importer associates each block with the printed `TEST n` label; PDF internal object order is 1,2,3,4,5,7,8,6,9,10, and must never be treated as test order. Corrections and audits in the data folder are deliberate source-backed inputs to regeneration, not disposable output. Part 5 prompts, all 40 Part 6 passages/160 blanks, 20 insertion passages/80 positions, photographs and listening graphics were visually checked against originals. Part 7 layout overrides preserve two-column reading order, tables and continuation documents.
