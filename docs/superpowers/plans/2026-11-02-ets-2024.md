# ETS 2024 Implementation Plan

> **For agentic workers:** Use executing-plans and test-driven-development. Data import, UI and API have separate ownership and can run in parallel under dispatching-parallel-agents.

**Goal:** Add the approved ETS 2024 text-based test and Part practice feature.
**Architecture:** Local OCR produces auditable structured JSON. Server catalog exposes only public question fields; authenticated APIs grade and persist independent ETS attempts. React views reuse the current shell and design.
**Tech Stack:** Installed Next.js 16.4.3, React 19, TypeScript, Supabase, local Windows OCR, Poppler and bundled Python.
**Spec:** `docs/superpowers/specs/2026-11-02-ets-2024-design.md` (approved by user: “Chốt”).

## Global Constraints

- Existing checkout is explicitly selected by the approved design; preserve all unrelated uncommitted work. Do not commit unrelated files.
- 10 tests, 200 questions each, 7 Parts; retain source question numbering and original choices/answers. No invented content.
- Native text and isolated necessary illustrations, no PDF/page-image fallback.
- Answer keys and transcripts remain server-only until submission.
- Independent ETS persistence and no EXP changes; full test 120 minutes, Part untimed.
- Read installed Next documentation before edits. Use local OCR only.

## Review Focus

- OCR must preserve multi-column order, question groups, and tables.
- Listening Parts 1–2 must not show spoken alternatives before submission.
- Reload at/after deadline must submit the saved attempt once.
- Cross-account drafts and results must remain isolated.
- Duplicate submissions with changed content must fail without replacing history.

## Shared interfaces

`lib/ets/types.ts`: `EtsChoice {label:string;text:string}`, `EtsBlock {type:'text'|'image'|'table';text?:string;src?:string;alt?:string;rows?:string[][]}`, `EtsQuestion {number:number;prompt:string;choices:EtsChoice[];answer:string}`, `EtsGroup {id:string;blocks:EtsBlock[];questions:EtsQuestion[];transcript?:string}`, `EtsPart {number:number;title:string;groups:EtsGroup[];audio?:{src:string;start?:number;end?:number}}`, `EtsTest {id:number;title:string;audioSrc:string;parts:EtsPart[]}`. Public variants omit `answer` and `transcript`. Source references can be optional additional fields. Data: `data/ets-2024/tests.json` array.

API: GET `/api/ets?test=1&part=0` returns `{sessions:EtsResult[]}`; POST receives `{id:string,testId:number,part:number,answers:Record<string,string>,durationMs:number}` where part 0=full. Returns `{id,testId,part,score,total,durationMs,createdAt,results:[{number,selected,expected,correct}],transcripts?:Record<string,string>}`. Errors `{error:string}`. Public catalog functions `getEtsTest(id:number)`, `getPublicEtsTest(id:number)`, `listEtsTests()`; lists contain metadata/count only.
