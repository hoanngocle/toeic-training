# Reading Implementation Plan

> **For agentic workers:** Use superpowers:executing-plans to implement task by task.

**Goal:** Convert all Reading exercises to text MCQs with immediate answer explanations.
**Architecture:** Add reviewed static reading content; merge into catalog and importer. Keep A–D as answer IDs. Server returns explanation only after grading; UI displays passages, prompts, choice text and result feedback.
**Tech Stack:** Existing Next.js 16, React 19, TypeScript, JSON, node:test.
**Spec:** ../specs/2026-11-01-reading-design.md

## Constraints
Preserve 50 lessons / 700 reading questions, original keys, existing retry and persistence behavior. No external services or dependencies. Read installed Next docs. Workspace has no Git repository.

## Review Focus

- Wrong-only retries must retain passage and selected scope.
- Old saved sessions must remain displayable.
- OCR must preserve full passage and option text.
- Long options and passages must fit mobile layouts.
