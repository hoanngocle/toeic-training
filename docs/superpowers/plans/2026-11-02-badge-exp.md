# Badge EXP implementation plan

**Goal:** Add 0.5 percentage points per badge tier, sum every unlocked badge, without a total cap, and retain the current level thresholds.

**Architecture:** Derive the unlocked collection from trusted saved history before each submission. Apply the additive bonus to the integer base reward, flooring once, and store a versioned calculation with its snapshot. Newly earned badges apply from the next submission. Preserve historical rewards and replay behavior.

**Approaches:** The user chose summing all unlocked tiers rather than replacing lower tiers with the highest tier in a category. Both use a 0.5% tier step; only the cumulative approach is implemented.

**Tech stack:** Existing TypeScript reward modules, Supabase PostgreSQL migrations, React achievement and reward views.
